Use case: infographic-diagram
日本語の教育用インフォグラフィックを完成品として1枚制作する。横長3:2、高精細3072×2048を希望。正確でくっきりした日本語と英数字を最優先。

参照画像の役割:
1. infographic-k.png はユーザーが添付した1枚目。構図、6コマの枠、引き出し線つきの白い札、文字の大きさ、水彩の絵柄、青い猫のレストラン世界観をそのまま踏襲する最重要の参照。既存文字をそのまま写すのではなく、以下の全文を正確に組み直す。
2. _style-clean.png は画風の補助参照。水彩、白基調、淡い彩度、紙の質感。
3. _ref-cat.jpg は主役の顔と配色の厳密な基準。大きな丸い青黒の瞳、青い毛、白い前髪と口元と手、ピンクの鼻、青いスーツと蝶ネクタイ。この同じ主役が各コマに登場。執事も青い猫で黒い燕尾服。登場人物は猫のみ。

主眼:
「何が変わったか」だけでなく、「なぜカッコに型を書くだけで中身が届くのか」を6つのレストラン場面で順番に追える。各コマに上部の大きな情景イラスト、たとえの見出し、小さな「しくみ」見出しと実際のプログラムで起こる説明、指定された小さなコード片を配置する。絵が画面のおよそ半分以上。6コマを最大の面積にする。指定文の短い改行はよいが省略や言い換えはしない。日本語をぎゅうぎゅうに詰めず十分大きく。特に最下部の付箋は4行が読めるだけの高さと幅を確保する。

画風:
参照1と同じ繊細な水彩イラスト、白〜淡いクリーム背景、青基調、彩度低め、窓の外の青い屋根の街並み、白い花、柔らかい自然光、レストランの木と真鍮。文字の背面は白く明瞭に。コマは角丸の青い細線、水彩の縁取り。引き出し線の札は白地、青い輪郭、青い線と先端の丸点。見出しは大きな濃紺の日本語セリフ体。本文ははっきり読める整った日本語。タイトルは非常に大きな濃紺のセリフ体。既存参照の彩色とサイズ比を守り、余分な装飾や不要な文章を加えない。

レイアウトと全文:

【上部タイトル】
Dependency Injection
その下の日本語:
なぜ「カッコに型を書くだけ」で、中身が届くのか
その下の細い帯に3つの用語:
コントローラ＝ページを見せてと言われたときに動く処理　／　引数＝カッコの中、材料を書く場所　／　型＝「これは記事」という名札

【上の細い比較帯】
帯の見出し「何が変わったか」。高さ控えめ、左右に小さなコード枠を1つずつ。
左の淡い赤の小見出し「これまで」。コードは正確に:
public function show($id)
{
    $article = Article::findOrFail($id);
}
右の淡い青の小見出し「DI」。コードは正確に:
public function show(Article $article)
{
}
中央に右向きの矢印、その下に:
探す1行が消えた。では、誰が探しているのか？

【本体6コマ：上段左から1,2,3、下段左から4,5,6】
各コマ左上に番号入りの青い丸。③だけ赤い番号丸と目立つ赤い枠。太い青矢印で1→2→3→4→5→6をつなぐ。3→4は段間の通路を右上から左下へ向かう折れ線で結び、矢印の先端は4だけに向ける。本文や絵の顔を線で横切らない。

【1】
上部の大きな絵: 青い主役猫がレストランの席に着く。白いテーブルクロス、番号札「1」、窓外の街並み。番号札に向かう引き出し線の札「/articles/1」。
たとえの見出し「席に着く」
小見出し「しくみ」

URLの表記はくっきり等幅風にする。

【2】
上部の大きな絵: 青い主役猫が小さな注文票に「Article」とだけ書いている。紙とペン、楽しげな顔。注文票への引き出し線の札「注文票＝引数の型」。

【3】
このコマだけ目立つ赤い枠と赤い星印をつける。
上部の大きな絵: 厨房のスイングドアの手前で燕尾服の執事猫が「Article」の注文票を先に読んでいる。ドアはまだ閉じ、丸窓から奥の厨房が少しだけ見える。主役の客猫は背景の席に座ったまま、テーブル番号は1。執事に向かう引き出し線の札「執事＝Laravel」。
たとえの見出し「執事が先に読む」、左に赤い星。
小見出し「しくみ」
説明:
メソッドが動く前に、Laravel がカッコの型を読む。ここが一番のポイント。
文字を潰さず短い2行に折り返してよい。

【4】
上部の大きな絵: 執事猫が「Article」の注文票とテーブル番号札「1」を見比べる。手元に「Article」と表紙に書かれた台帳が開いており、そのページに大きな「id」。idを指す引き出し線の札「id」。

小さな白いコード枠:
$primaryKey = 'id'
大文字Kを必ず守る。primaryKeyをprimarykeyにしない。

【5】
上部の大きな絵: 執事猫が厨房で「articles」と書かれた青い円筒の樽から、番号「1」の光る書類を1枚そっと取り出す。厨房への引き出し線の札「厨房＝データベース」。
たとえの見出し「厨房で取り出す」
小見出し「しくみ」

【6】
上部の大きな絵: テーブルの銀のクローシュのふたを執事が持ち上げ、中に番号1の光る書類がある。主役猫はそれを見て笑顔で両手を広げる。書類への引き出し線の札「届いた記事＝$article」。
たとえの見出し「届いてから始まる」
小見出し「しくみ」
説明:

【下の帯】
見出し「つまり、こういうこと」
3つの小さな横並びカード、番号とアイコン付き。カード1は注文票とペン、2はArticleの名札、3はidの台帳。
カード1:
1　メソッドが動く前に、Laravel が引数を読んでいる
だから中に入った時点で、もう入っている。
カード2:
2　型に書いた「Article」が、どのテーブルを見るかの目印
名札を見て、記事の棚を見に行く。
カード3:
3　どの列で探すかは Article 自身が持っている
$primaryKey = 'id' なので、id で探す。書いていないのに id なのはこれが理由。

文字・記号の品質制約:
全文を上の指定通りに描く。日本語も英数字も正確でくっきり、十分なサイズ。漢字のへん・つくりを正しく。コードの引用符はまっすぐな半角のシングルクォート ' のみ。スマートクォートにしない。波括弧 { } と丸括弧 ( ) は明確に区別。特に最下部 Route::get('/articles/{article}', ...) の article の両側は左波括弧 { と右波括弧 }。コードの呼び出し全体の両側だけ丸括弧 ( )。/articles/(article) を絶対に描かない。型ArticleのAは大文字、テーブルarticlesは小文字、$primaryKeyのKは大文字。すべてのコンテンツが画像内に収まり切れるようにする。
