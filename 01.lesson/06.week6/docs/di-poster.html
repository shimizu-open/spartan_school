その仕事に どうしても必要な相棒
＋
注入INJECTION

＝

2

同じ「記事を表示する」仕事を、2通りで

自分で買い出しに行くBEFORE
public function show($id)
{
    $article = Article::findOrFail($id);
    // ↑ 探す仕事を自分で抱えている
    return view('articles.show', …);
}
本題の前に、材料集めで疲れ果てる
▶
注文に変える
注文して、届けてもらうAFTER
public function show(Article $article)
{
    // 記事はもう手元にある

    return view('articles.show', …);
}
探す行が消え、本来の仕事だけが残る
