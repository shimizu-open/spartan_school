
■ 文字・記号の品質
日本語も英数字もすべて正確に、くっきり読めるように描くこと。誤字や崩れた文字を作らないこと。
画数の多い漢字も、へんとつくりを取り違えず正しい字形で描くこと。
コードの引用符はまっすぐな半角のシングルクォート（'）にすること。カーリークォート（’）にしない。
波括弧 { } と丸括弧 ( ) 、角括弧 [ ] を取り違えないこと。コード枠の中の -> は「半角ハイフン」と「半角の不等号 >」の2文字で描く。矢印記号 → に置き換えない（例：$table->softDeletes() / $model->delete()）。
すべての内容が画像内に収まり切れるようにすること。
