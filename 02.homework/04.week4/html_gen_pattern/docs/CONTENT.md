# 原稿（CONTENT.md）

`SPEC.md` に付随する原稿ファイル。
**ここに書かれた事実以外を本文に書かないこと。創作・脚色・「それらしい追記」は全面禁止。**

理由：これは資料館である。展示物が間違っていたら資料館の意味がない。
生成AIが年号や作品名を「もっともらしく」補完すると、学習者はそれを事実として覚えてしまう。
**書いていないことは書かない。足りないと感じたら空欄のままにし、`REPORT.md` に報告すること。**

### 掲載する9人

各人物は次の項目を持つ。**表にない項目は書かないこと。**

---

**1. シャーロック・ホームズ**
- 英語表記：`Sherlock Holmes`
- 肩書き：諮問探偵（Consulting Detective）
- 住所：ロンドン ベイカー街221B
- 初登場：緋色の研究（1887年）
- 解説：
  ```
  世界で唯一の「諮問探偵」を名乗る。警察や私立探偵が行き詰まった事件に助言を与える職業を、
  自ら定義して始めた人物。観察と推理を武器とし、ヴァイオリンを弾き、化学実験を好む。
  ```

---

**2. ジョン・H・ワトスン**
- 英語表記：`John H. Watson`
- 肩書き：医師、記録者
- 初登場：緋色の研究（1887年）
- 解説：
  ```
  元軍医。アフガニスタンでの従軍から負傷して帰国し、下宿を探していたところで
  ホームズと出会い、221Bを共同で借りることになる。
  正典のほとんどは、このワトスンが書いた記録という体裁をとっている。
  ```

---

**3. ハドスン夫人**
- 英語表記：`Mrs. Hudson`
- 肩書き：221Bの家主
- 解説：
  ```
  ベイカー街221Bの家主。奇妙な訪問者や銃声、化学実験の臭いに耐えながら、
  下宿人であるホームズとワトスンの生活を支える。
  ```

---

**4. マイクロフト・ホームズ**
- 英語表記：`Mycroft Holmes`
- 肩書き：ホームズの兄、英国政府の官吏
- 解説：
  ```
  ホームズの7歳年上の兄。推理の才ではホームズを上回るとされるが、
  自ら足を運んで調べることを好まない。ディオゲネス・クラブの創立者の一人。
  ```

---

**5. レストレード警部**
- 英語表記：`Inspector Lestrade`
- 肩書き：スコットランドヤードの警部
- 初登場：緋色の研究（1887年）
- 解説：
  ```
  ロンドン警視庁（スコットランドヤード）の警部。正典に最も多く登場する警察官。
  実直で粘り強いが、目に見える事実の先を読む想像力に欠ける。
  ```

---

**6. モリアーティ教授**
- 英語表記：`Professor James Moriarty`
- 肩書き：数学者、犯罪組織の首領
- 初登場：最後の事件（1893年）
- 解説：
  ```
  ホームズが「犯罪界のナポレオン」と呼ぶ人物。元は数学の教授であり、
  ロンドンの犯罪の多くを背後から統括しているとされる。
  「最後の事件」でホームズと対決する。
  ```

---

**7. アイリーン・アドラー**
- 英語表記：`Irene Adler`
- 肩書き：オペラ歌手
- 初登場：ボヘミアの醜聞（1891年）
- 解説：
  ```
  「ボヘミアの醜聞」に登場する女性。ホームズの計略を見破って出し抜いた。
  ワトスンによれば、ホームズは彼女をつねに「あの女性（the woman）」と呼んだ。
  ```

---

**8. セバスチャン・モラン大佐**
- 英語表記：`Colonel Sebastian Moran`
- 肩書き：元陸軍大佐、狙撃手
- 初登場：空き家の冒険（1903年）
- 解説：
  ```
  モリアーティの組織で最も危険とされた人物。優れた狙撃手であり、
  「空き家の冒険」でホームズが仕掛けた罠にかかる。
  ```

---

**9. ベイカー街遊撃隊**
- 英語表記：`The Baker Street Irregulars`
- 肩書き：ロンドンの street children による情報網
- 初登場：緋色の研究（1887年）
- 解説：
  ```
  ホームズが雇うロンドンの浮浪児たちの集団。
  大人が入り込めない場所を歩き回り、街の情報を集めてくる。
  ```

| 1901 | 『バスカヴィル家の犬』連載開始 | ストランド誌で連載。滝の事件より前の出来事として発表された。翌1902年に単行本化。 |

| 1927 | 『シャーロック・ホームズの事件簿』刊行 | 最後の短編集。これをもって正典60編が完結する。 |
| 1930 | コナン・ドイル没 | 71歳。 |
| 2023 | 正典全作品がパブリックドメインに | 米国において、最後まで権利が残っていた作品の保護期間が満了し、正典60編すべてが自由に利用できるようになった。 |

## §6 事実確認メモ（実装者向け・厳守）

原稿中の事実は以下のとおり確定している。**変更・追加しないこと。**

- 正典は長編4作・短編56作の計60作
- 長編4作：緋色の研究（1887）／四つの署名（1890）／バスカヴィル家の犬（1901年連載開始・1902年単行本）／恐怖の谷（1914年連載開始・1915年単行本）
- 短編集5冊：冒険（1892）／回想（1893）／帰還（1905）／最後の挨拶（1917）／事件簿（1927）
- 『緋色の研究』の初出はビートンのクリスマス年鑑
- 『四つの署名』の初出はリッピンコット月刊誌
- 短編の主な連載誌はストランド・マガジン。連載開始は1891年、第1作は「ボヘミアの醜聞」
- 「最後の事件」は1893年発表。ライヘンバッハの滝
- 「空き家の冒険」は1903年発表。ホームズの生還
- コナン・ドイルの生没年は 1859-1930（エディンバラ生まれ、没年71歳）
- 2023年に米国で正典全作品がパブリックドメイン化
- マイクロフトはホームズの7歳年上の兄

### 特に禁止すること

- **短編集ごとの収録編数を書かない**（版によって異なるため）
- **事件が起きた「作中の年」を書かない**（研究者間で見解が分かれており、確定していない）
- **ホームズやワトスンの生年・年齢を書かない**（正典に明記がない）
- **上記6か所以外の地名を地図に追加しない**
- **上記9人以外の人物を名鑑に追加しない**
- **個々の短編のあらすじを書かない**（原稿にない）
