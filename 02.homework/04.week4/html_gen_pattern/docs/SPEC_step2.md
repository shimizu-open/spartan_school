# 仕様書 STEP2：年表ページを追加する

STEP1 で `index.html` / `style.css` / `main.js` の1枚ものができている。
今回はそこに**年表ページを1枚足し、2ページのサイトにする**。

原稿は `CONTENT.md` の §0（共通要素）と §3（年表）を使う。
`SPEC.md` は完成形の設計図なので今回は無視する。

## 作る／触るファイル

```
html_gen_pattern/
├── index.html        ← 【修正】ヘッダーとカードを2ページ構成に対応させる
├── chronology.html   ← 【新規】年表ページ
├── style.css         ← 【修正】共通部分はここのまま。年表用のスタイルを追記
└── main.js           ← 【修正】必要なら年表用の処理を追記
```

CSS と JS はファイルを分けず、既存の2ファイルに追記する。
（2ページ程度で分割すると、かえって管理が面倒になるため。この判断理由をCSSの冒頭にコメントで書く）

画像は使わない。外部ライブラリ・CDN・Webフォントも使わない。ブラウザ直開きで動くこと。

## 1. `chronology.html`（新規）

### 採用するレイアウトパターン

- **骨格：1カラム**
- **ナビ：ヘッダーナビ ＋ ハンバーガー**（`index.html` と完全に同じもの）
- **中身：タイムライン**

理由をページ冒頭のHTMLコメントに書くこと。
「時系列は縦一本が最も読みやすく、横に何か置くと読む流れを邪魔するから」など。

### 中身

1. **ヘッダー**：`index.html` と同一。ただし現在地が年表であることを示す
2. **ページ見出し**
   - h1：`年表`
   - リード文：`CONTENT.md` §3 のリード文をそのまま
3. **年表本体**：`CONTENT.md` §3 の表の**14項目を、書かれている順のまま**
4. **フッター**：`index.html` と同一

### タイムラインの実装要件

- **`<ol>` でマークアップする。** 順序に意味があるため。
  「なぜ `ul` ではなく `ol` なのか」をコメントで説明すること
- 年は `<time datetime="1887">1887</time>` の形で書く。
  `datetime` 属性は機械が読むための表記であることをコメントで説明すること
- 縦の1本線を CSS の疑似要素（`::before`）で描き、各項目に丸い印を置く
- 年のラベルは `position: sticky` でスクロール中に上に留まる
- スクロールで各項目がフワッと現れる（`IntersectionObserver` を使う。
  `scroll` イベントの直接監視は禁止。理由をコメントに書く）
- **1930年と2023年の間は93年空く。** ここだけ間隔が空いていることが視覚的に分かる表現にすること
  （区切りを入れる、余白を大きく取る、など。やり方は任せる）
- 768px 以下：線を左端に寄せ、年と本文を縦に積む

## 2. `index.html`（修正）

### ヘッダーを2ページ構成にする

現在のヘッダーはページ内リンク3つ（館内案内／資料館について／数字）になっている。
これを**ページ間のリンクを含む形**に変える。

| 表示 | リンク先 |
|---|---|
| 館内案内 | `index.html`（`chronology.html` からはこれで戻る） |
| 年表 | `chronology.html` |

- 今いるページのリンクには `aria-current="page"` を付け、視覚的にも区別する
  （`aria-current` が何のためのものかをコメントで説明すること）
- 両ページでヘッダーのHTMLを**完全に同じ形**にする（現在地の印だけが違う状態）

### 館内案内カードを更新する

4枚のうち **年表のカードだけをリンクにする**。
残り3枚（人物名鑑・作品総覧・ロンドン地図）は「準備中」ラベルのまま `article` で据え置く。

- リンクになったカードは、カード全体が押せること
- ホバー・フォーカス時に、押せることが分かる見た目にすること

## 3. 守ること（STEP1 と同じ）

- `<!DOCTYPE html>` / `<html lang="ja">` / `<meta charset="UTF-8">` / viewport
- セマンティックタグを使う。`h1` は各ページ1つ、見出しレベルを飛ばさない
- 開閉ボタンは `<button>`。キーボードだけで全部操作できる
- コントラスト比 4.5:1 以上
- 色をハードコードせず、既存の `:root` のカスタムプロパティを使う
- **`element.style.xxx = ...` を書かない。** クラス・`data-` 属性の切り替えだけ
- `var` 禁止
- 禁止：レイアウト目的の `<table>` と `float`、`<center>` `<font>` `<b>`、
  インラインスタイル、`<br>` による余白調整、外部ライブラリ
- コメントは日本語で、「何をしているか」ではなく「なぜそうするか」を書く

## 4. 内容の正確さ

`CONTENT.md` に書かれていない事実を**1つも書かないこと**。
年号・作品名を創作しない。特に §6「事実確認メモ」の禁止事項を守ること。
足りないと感じても空欄のままにして報告すること。

## 5. 分量の目安

- `chronology.html` … 120〜170行
- `style.css` への追記 … 100〜150行
- `main.js` への追記 … 20〜40行

大きく超えたら盛りすぎなので削ること。
