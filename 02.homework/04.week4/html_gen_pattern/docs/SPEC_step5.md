原稿は `CONTENT.md` の §0（共通要素）と §5（ロンドン地図）を使う。

あわせて `position: sticky` の応用と、スクロール位置と表示の連動を扱う。

## 1. `london.html`（新規）

### 採用するレイアウトパターン

- **骨格：スプリット（左右2分割・片側固定）**
- **ナビ：ヘッダーナビ ＋ ハンバーガー**（既存4ページと同一）

理由をページ冒頭のHTMLコメントに書くこと。
「解説を読むあいだ地図を見失わせたくないので、片側を固定した」など。

### 構造

```html
<div class="map-layout">
  <div class="map-pane">              <!-- 左：固定 -->
    <figure class="map-figure">
      <img src="images/map-london.jpg" alt="ロンドン市街の図案。物語に登場する6か所の位置関係を示す">
      <button class="pin" data-target="baker-street" style-は使わない…>…</button>
      …6つ
      <figcaption>この地図は正確な縮尺の地図ではなく、位置関係を示す図案です。</figcaption>
    </figure>
  </div>
  <div class="places-pane">           <!-- 右：スクロール -->
    <section id="baker-street">…</section>
    …6つ
  </div>
</div>
```

### 左（地図）の要件

- 幅 55%。`position: sticky` で画面に留める
- 6つのホットスポットは **`<button>`** を使う（`<div>` は不可）
- 位置指定は `position: absolute` ＋ `%`。
  **`%` を使う理由をコメントに書くこと**（`px` だと画像が伸縮したときズレるため）
- **位置の指定はインラインスタイルではなく CSS クラスで行う**
  （`.pin--baker-street { top: 32%; left: 41%; }` のように、場所ごとにクラスを作る）
- ホットスポットにはラベルを付ける（`aria-label` に地名を入れる）
- ホットスポットの当たり判定は **44px × 44px 以上**にする
  （小さすぎると押せない。これはアクセシビリティの目安）
- **`<figcaption>` に縮尺の注記を必ず入れる**

### 右（解説）の要件

- 幅 45%。`CONTENT.md` §5 の6か所を、書かれている順に縦に並べる
- 各項目：地名（h2）／英語表記／解説（p）
- 各 `<section>` に `id` を付け、ホットスポットの `data-target` と対応させる

### 連動の要件

1. **ホットスポットを押すと**、対応する解説へスクロールし、両方がハイライトされる
2. **右をスクロールすると**、画面中央にある解説に対応するホットスポットが光る
   - `IntersectionObserver` を使う。`scroll` イベントの直接監視は禁止
   - `rootMargin` で「画面中央の帯」を判定範囲にする

ハイライトは**クラスの付け外し**で行う（`element.style` は使わない）。

### レスポンシブ（重要）

**この型は狭い画面では成立しない。** 地図上の小さな印は指で押せない。

- 900px 以下：`position: sticky` を解除し、地図を上・解説を下の縦積みにする
- **狭い画面ではホットスポットを非表示にし、解説リストを主役にする**
- **この判断理由をHTMLコメントに明記すること**
  「小さな印は指で押せないため、狭い画面では地図を参考図に格下げし、
  解説リストから読ませる作りに切り替える」

## 3. 守ること

- `<!DOCTYPE html>` / `<html lang="ja">` / `<meta charset="UTF-8">` / viewport
- セマンティックタグを使う。`h1` は各ページ1つ、見出しレベルを飛ばさない
- ホットスポットは `<button>`。キーボードだけで全部操作できる
- コントラスト比 4.5:1 以上
- 色をハードコードせず、既存の `:root` のカスタムプロパティを使う
- **`element.style.xxx = ...` を書かない。インラインスタイルも使わない**
- `var` 禁止
- 禁止：レイアウト目的の `<table>` と `float`、`<center>` `<font>` `<b>`、
  `<br>` による余白調整、外部ライブラリ
- コメントは日本語で、「何をしているか」ではなく「なぜそうするか」を書く

## 4. 内容の正確さ

`CONTENT.md` §5 に書かれていない事実を**1つも書かないこと**。

- **指定6か所以外の地名を追加しない**
- 実在の座標を調べて書かない（あくまで図案上の配置である）
- 221Bの住所が架空であることの記述は、原稿のとおりに書く
