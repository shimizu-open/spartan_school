まず1枚だけ作る。ここが動いてから増やす。
`SPEC.md` は完成形の設計図であり、**今回は使わない**。原稿は `CONTENT.md` の §0 と §1 だけ使う。

## 作るファイル（3つだけ）

```
html_gen_pattern/
├── index.html
├── style.css
└── main.js
```

画像は使わない。ヒーローの背景は CSS のグラデーションで作る。
外部ライブラリ・CDN・Webフォントは使わない。ブラウザ直開きで動くこと。

## 採用するレイアウトパターン

- **骨格：1カラム**（header → main → footer を縦に積むだけ）
- **ナビ：ヘッダーナビ ＋ ハンバーガー**（狭い画面では ☰ に畳む）
- **中身：ヒーロー ＋ カードグリッド**

理由を `index.html` の冒頭にHTMLコメントで書くこと。
「見せるだけのページなので横に何も置かない」「入口が4つなので上部バーに収まる」など。

## 見た目

`:root` にカスタムプロパティとして定義し、色をハードコードしない。

| 変数 | 値 |
|---|---|
| `--bg` | `#0d0f12` |
| `--bg-elev` | `#14171c` |
| `--line` | `#262b33` |
| `--text` | `#e6e4df` |
| `--muted` | `#8c8f96` |
| `--accent` | `#c8a45c` |
| `--header-h` | `64px` |

- 見出しはセリフ体、本文はサンセリフ体（システムフォントで指定）
- アクセント色は差し色。面で塗らず、線・小さな文字・ホバー時にのみ使う

## 使う技法（それぞれ、なぜ使うかをコメントで1行書く）

1. `clamp()` … 画面幅で文字サイズが伸縮する
2. `repeat(auto-fill, minmax(220px, 1fr))` … メディアクエリなしでカードの列数が変わる
3. `scroll-padding-top` … ページ内リンクで飛んだ先が固定ヘッダーに隠れないようにする
4. `max-width: 65ch` … 1行が長すぎると読みにくいので文字数で制限する
5. `prefers-reduced-motion` … アニメーションが苦手な人には動きを止める

## JavaScript（ハンバーガーだけ）

- `<button>` のクリックで `header` に `is-open` クラスをトグルする
- `aria-expanded` と `aria-label` を更新する
- メニュー内リンクのクリックで自動的に閉じる
- Esc キーで閉じ、フォーカスをボタンに戻す
- **`element.style.xxx = ...` を書かないこと。** クラスの切り替えだけを行い、
  見た目の変化はCSSに任せる。この理由をコメントに書く
- `var` 禁止

## 守ること

- `<!DOCTYPE html>` / `<html lang="ja">` / `<meta charset="UTF-8">` / viewport
- セマンティックタグ（`header` `nav` `main` `section` `article` `footer`）を使う
- `h1` は1つ、見出しレベルを飛ばさない
- 開閉ボタンは `<button>`（`<div onclick>` は不可）
- キーボードだけで全部操作できる
- 本文と背景のコントラスト比 4.5:1 以上
- 禁止：レイアウト目的の `<table>` と `float`、`<center>` `<font>` `<b>`、
  インラインスタイル、`<br>` による余白調整、外部ライブラリ
- コメントは日本語で、「何をしているか」ではなく「なぜそうするか」を書く

## 内容の正確さ

`CONTENT.md` に書かれていない事実を1つも書かないこと。
年号・作品数を創作しないこと。足りないと感じても空欄のままにして報告すること。

## 分量の目安

`index.html` 120〜180行、`style.css` 180〜250行、`main.js` 30〜50行。
これを大きく超えたら盛りすぎなので削ること。
