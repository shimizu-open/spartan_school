## 1. `works.html`（新規）

### 採用するレイアウトパターン

- **骨格：2カラム（Flexbox）**
- **ナビ：ヘッダーナビ ＋ ハンバーガー**（既存3ページと同一）
- **中身：カードグリッド**

理由をページ冒頭のHTMLコメントに書くこと。
「絞り込みを常に触れる位置に置きたいので、本文の横にサイドバーを立てた」など。

### 構造

```html
<div class="layout">
  <aside class="filters" aria-label="絞り込み">…</aside>
  <main>…</main>
</div>
```

**サイドバーは左に置く。**
理由：これは読み物ではなく**操作するもの**であり、操作は本文より先に目に入ったほうがよいため。
（読み物なら右が基本。この使い分けをHTMLコメントに書くこと）

### CSS の要件

```css
.layout  { display: flex; gap: 40px; align-items: flex-start; }
main     { flex: 1; min-width: 0; }
.filters { flex: 0 0 220px; position: sticky; top: calc(var(--header-h) + 24px); }
```

**`min-width: 0` には必ずコメントを添えること。**
「Flexbox の子要素には『中身より小さくならない』既定の設定があり、
長い英題などがあるとサイドバーを押しのけて崩れる。この1行はその既定設定の解除である」

### 絞り込み（左カラム）

| 絞り込み名 | 選択肢 |
|---|---|
| 種別 | すべて ／ 長編 ／ 短編集 |
| 年代 | すべて ／ 1880年代 ／ 1890年代 ／ 1900年代 ／ 1910年代 ／ 1920年代 |

- ラジオボタン（`<input type="radio">`）を使い、`<label>` で必ず紐づける
  （`<label for="...">` かラベルで囲む。**紐づけると文字を押しても選べるようになる**。
  この理由をコメントに書くこと）
- 種別と年代はそれぞれ独立したグループ。`<fieldset>` と `<legend>` で囲む
- 初期状態はどちらも「すべて」

### 一覧（右カラム）

- `CONTENT.md` §4 の9冊を**発表年の昇順**でカードグリッドに並べる
- `repeat(auto-fill, minmax(220px, 1fr))` を使う
- 各カードに：発表年 ／ 邦題（h3）／ 英題 ／ 説明
- **収録編数は書かない**（版によって異なるため。`CONTENT.md` §6 の禁止事項）

### 絞り込みの実装要件

- **`hidden` 属性の付け外しで実現する。** `style.display` は使わない
  （見た目の定義がCSSとJSに散らばるのを避けるため。この理由をコメントに書く）
- 絞り込み結果の件数を「**9件中4件を表示**」の形で表示する
- 件数表示に `aria-live="polite"` を付ける
  （画面を見ていない人にも結果の変化が伝わるようにするため。理由をコメントに書く）
- **0件になったときのメッセージを必ず用意する**
  （忘れると無言の空白になり、壊れたように見える）

### レスポンシブ

- 900px 以下：`flex-direction: column`。**絞り込みが上、一覧が下**
- 縦積みのとき `position: sticky` を解除する

## 3. 守ること

- `<!DOCTYPE html>` / `<html lang="ja">` / `<meta charset="UTF-8">` / viewport
- セマンティックタグを使う。`h1` は各ページ1つ、見出しレベルを飛ばさない
- キーボードだけで絞り込みを操作できること
- コントラスト比 4.5:1 以上
- 色をハードコードせず、既存の `:root` のカスタムプロパティを使う
- **`element.style.xxx = ...` を書かない**
- `var` 禁止
- 禁止：レイアウト目的の `<table>` と `float`、`<center>` `<font>` `<b>`、
  インラインスタイル、`<br>` による余白調整、外部ライブラリ
- コメントは日本語で、「何をしているか」ではなく「なぜそうするか」を書く

## 4. 内容の正確さ

`CONTENT.md` §4 に書かれていない事実を**1つも書かないこと**。

- **短編集ごとの収録編数を書かない**（版によって異なる）
- 年号・邦題・英題を創作しない
- 9冊以外を追加しない

- `works.html` … 180〜240行
- `style.css` への追記 … 100〜150行
- `main.js` への追記 … 40〜70行
