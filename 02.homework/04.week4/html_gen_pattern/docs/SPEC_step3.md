# 仕様書 STEP3：人物名鑑ページを追加する

STEP2 までに `index.html`（エントランス）と `chronology.html`（年表）の2ページができている。
今回は**人物名鑑を追加して3ページにする**。

原稿は `CONTENT.md` の §0（共通要素）と §2（人物名鑑）を使う。
`SPEC.md` は完成形の設計図なので今回は無視する。

## このステップの学習ポイント

**JavaScript が初めてレイアウトの主役になる。**
STEP1・2 の JS はハンバーガーとフェードインだけで、無くてもページは成立していた。
ここからは JS が無いと画面が切り替わらない。

---

## 作る／触るファイル

```
html_gen_pattern/
├── index.html         ← 【修正】ヘッダーに人物名鑑を追加。カードをリンクに昇格
├── chronology.html    ← 【修正】ヘッダーのみ（3ページ構成に合わせる）
├── characters.html    ← 【新規】人物名鑑
├── style.css          ← 【修正】人物名鑑用のスタイルを追記
└── main.js            ← 【修正】人物名鑑用の処理を追記
```

CSS と JS はファイルを分けず、既存の2ファイルに追記する。
画像はまだ使わない（STEP6 で入れる）。外部ライブラリ・CDN・Webフォントも使わない。

## 1. `characters.html`（新規）

### 採用するレイアウトパターン

- **骨格：マスター＋ディテール**（左で選ぶと右に詳細が出る）
- **ナビ：ヘッダーナビ ＋ ハンバーガー**（既存2ページと同一）

理由をページ冒頭のHTMLコメントに書くこと。
「人物間を行き来する動きが中心なので、一覧を残したまま詳細を切り替えられる型にした」など。

### 中身

1. **ヘッダー**：既存2ページと同一。現在地が人物名鑑であることを示す
2. **ページ見出し**
   - h1：`人物名鑑`
   - リード文：`CONTENT.md` §2 のリード文をそのまま
3. **本体**：左に9人のリスト、右に選択中の人物の詳細
4. **フッター**：既存2ページと同一

### マスター（左）の要件

```html
<nav class="roster" aria-label="人物一覧">
  <ul>
    <li>
      <button type="button" data-target="holmes" aria-current="true">
        シャーロック・ホームズ
      </button>
    </li>
    …
  </ul>
</nav>
```

- リンクではなく **`<button>`** を使う（ページ移動ではなく表示切替なので）
- 選択中の項目に `aria-current="true"` を付け、視覚的にも区別する
- **上下矢印キーでリスト内を移動できること**（`keydown` で `ArrowUp` / `ArrowDown` を拾う）
- 初期表示はシャーロック・ホームズ

### ディテール（右）の要件

```html
<div id="detail" aria-live="polite">
  <article id="holmes" class="person">…</article>
  <article id="watson" class="person" hidden>…</article>
  …
</div>
```

各人物の `<article>` は次を含む。**原稿にない項目は作らないこと**（人物ごとに項目数が異なる）。

- 氏名（h2）
- 英語表記
- 肩書き・住所・初登場（`<dl>` / `<dt>` / `<dd>` で。**原稿にある項目だけ**）
- 解説（p）
- ポートレート画像の場所を `aspect-ratio: 1` で確保しておく
  （STEP6 で画像が入る。今は `--bg-elev` の面と頭文字だけを表示する）

### 最重要の設計（違反不可）

> **9人分のデータは JS の中ではなく HTML に全部書く。**
> **JS は `hidden` 属性を付け外しするだけ。**

こうすると JavaScript が動かなくても9人全員の情報が読める。
`main.js` にこの設計理由をコメントで明記すること。

### レスポンシブ

- 900px 以下：左右に並べず、**リストが上・詳細が下**の縦積みにする
- 縦積みのとき、リストの項目を押したら詳細の位置までスクロールする
  （押しても画面が変わらないように見えるのを防ぐため）
- **狭い画面ではマスター＋ディテールが本来成立しない型である**ことを、
  HTMLコメントで説明すること（「一覧→タップ→詳細」の2画面に分けるのが本来の解）

## 4. 守ること

- `<!DOCTYPE html>` / `<html lang="ja">` / `<meta charset="UTF-8">` / viewport
- セマンティックタグを使う。`h1` は各ページ1つ、見出しレベルを飛ばさない
- 切替ボタンは `<button>`。キーボードだけで全部操作できる
- コントラスト比 4.5:1 以上
- 色をハードコードせず、既存の `:root` のカスタムプロパティを使う
- **`element.style.xxx = ...` を書かない。**
  `hidden` 属性・クラス・`data-` 属性の切り替えだけを使う
- `var` 禁止
- 禁止：レイアウト目的の `<table>` と `float`、`<center>` `<font>` `<b>`、
  インラインスタイル、`<br>` による余白調整、外部ライブラリ
- コメントは日本語で、「何をしているか」ではなく「なぜそうするか」を書く

## 5. 内容の正確さ

`CONTENT.md` §2 に書かれていない事実を**1つも書かないこと**。
特に `CONTENT.md` §6 の禁止事項を守る。

- ホームズやワトスンの**生年・年齢を書かない**（正典に明記がない）
- 指定9人**以外の人物を追加しない**
- 個々の短編の**あらすじを書かない**
- 人物ごとに原稿の項目数が違う。**無い項目を埋めない**
  （例：ハドスン夫人には「初登場」の記載がない → その行を作らない）

足りないと感じても空欄のままにして報告すること。
