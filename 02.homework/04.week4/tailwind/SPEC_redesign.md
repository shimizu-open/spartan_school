# 仕様書：キャラクター紹介ページのデザイン改訂（探偵ファイル化）

既に `index.html` / `src/input.css` / `dist/output.css` があり、Tailwind v4 のビルドが通っている。
今回は**デザインを全面的に作り替え、画像を入れる**。

## 何が問題だったか

現状は「暗い背景＋金の差し色」で雰囲気は出ているが、**探偵ならではの記号が何もない**。
ダークテーマの汎用サイトと区別がつかない。

## 新しいデザイン方針：**ツイードの事件ファイル**

2つの記号系を掛け合わせる。

1. **探偵といえば思い浮かぶ見た目** … 鹿撃ち帽（ディアストーカー）、インヴァネスコート、
   パイプ、虫眼鏡、**茶色のツイード**、**千鳥格子（ハウンドトゥース）**
2. **捜査資料の体裁** … 事件ファイル番号、タイプライター体、赤いスタンプ、証明写真

**1が全体の色と質感を決め、2が情報の並べ方を決める。**
紙一色の書類ではなく、**ツイードの上に書類が乗っている**、という画にする。

### 補足：この見た目の出どころ（実装者向けの背景。ページ本文には書かないこと）

鹿撃ち帽とカーブしたパイプは、**原作の文章には由来しない**。
帽子はストランド誌の挿絵画家シドニー・パジェットが1891年の挿絵で描いたものが定着し、
カーブしたパイプは舞台俳優ウィリアム・ジレットが持ちやすさから使ったものが広まった。
つまり「その後100年で作られた記号」だが、記号としての強さは圧倒的である。
だからデザインでは**遠慮なく使う**。

（この経緯はページ本文に書かない。原稿にない事実を載せない方針のため）

### 具体的な記号（必ず盛り込む）

| 記号 | どう使うか |
|---|---|
| **ツイードの茶** | ページ全体の地色。暗めの茶で、上に書類が乗っている構図にする |
| **千鳥格子** | **CSS のグラデーションだけで作る**（画像を使わない）。ヘッダーの帯や区切りに細く使う |
| **鹿撃ち帽のシルエット** | インラインSVGで小さく作り、ロゴの隣とセクション見出しに置く |
| **虫眼鏡** | インラインSVG。ヒーローとリンクのホバーに使う |
| **書類の紙** | カードは羊皮紙色の紙。ツイードの地の上に乗る |
| **タイプライター体** | 見出しとラベルを等幅に。`--font-typewriter` を `@theme` に登録 |
| **ファイル番号** | 各人物に `CASE FILE No. 001` 〜 `009` を振る |
| **赤いスタンプ** | `WANTED` などを傾けて重ねる。`rotate-[-8deg]` |
| **証明写真** | 角丸なしの四角。セピア。細い枠 |
| **紙の傾き** | カードを `rotate-[0.3deg]` 程度わずかに傾け、重ねた紙束に見せる |

### 千鳥格子の作り方（画像を使わないこと）

外部画像を足すと S3 に上げるものが増える。**CSS のグラデーションで作る。**
`src/input.css` にユーティリティとして定義し、HTML からクラス名で呼ぶ。

```css
@utility houndstooth {
  background-color: var(--color-tweed);
  background-image:
    linear-gradient(45deg, var(--color-tweed-dark) 25%, transparent 25%, transparent 75%, var(--color-tweed-dark) 75%),
    linear-gradient(45deg, var(--color-tweed-dark) 25%, transparent 25%, transparent 75%, var(--color-tweed-dark) 75%);
  background-size: 12px 12px;
  background-position: 0 0, 6px 6px;
}
```

※上は市松に近い簡易版。**より千鳥格子らしい見え方に調整してよい**が、
画像を使わないことと、細かくしすぎて目が疲れる柄にしないことを守る。
**面で敷き詰めず、帯や区切りに細く使う**こと。

### 配色（`src/input.css` の `@theme` を書き換える）

| 変数名 | 値 | 用途 |
|---|---|---|
| `--color-tweed` | `#4a3c2e` | ツイードの茶。ページ全体の地色 |
| `--color-tweed-dark` | `#3a2f24` | 千鳥格子の濃いほう |
| `--color-paper` | `#efe9da` | 書類の紙。カードの面 |
| `--color-paper-edge` | `#d8cfb8` | 紙の端・罫線 |
| `--color-ink` | `#2b2723` | 本文。真っ黒にしない（インクの黒は少し茶色い） |
| `--color-faded` | `#6f675c` | 補助テキスト。褪せた文字 |
| `--color-brass` | `#c8a45c` | 真鍮。ツイード地の上の文字やアクセントに |
| `--color-stamp` | `#a83a2c` | 赤いスタンプ・印章 |

フォントも `@theme` に登録する。**Webフォントは読み込まない**（システムフォントのみ）。

```css
--font-typewriter: "Courier New", "Consolas", monospace;
--font-display: "Times New Roman", "Yu Mincho", serif;
```

### 避けること

- **やりすぎた「汚し」**。染みやコーヒー跡を画像で敷き詰めると読みにくくなる。
  紙らしさは色と罫線とフォントで出す
- **千鳥格子を面で敷き詰めない。** 背景一面にすると文字が読めない。帯・区切りに限定する
- **本文まで等幅にしない**。等幅は見出し・ラベル・番号だけ。長文が読みにくくなる
- スタンプを全カードに置かない。多用すると効かなくなる（後述）
- **帽子とパイプのSVGを大量に散らさない。** ロゴと見出しに絞る

## 1. 生成する画像（Codex の画像生成機能を使う）

`images/` に置く。**S3 にアップロードする対象が増えるので、枚数と容量に注意すること。**

### ポートレート9枚

| ファイル名 | 内容 |
|---|---|
| `p-holmes.jpg` | 痩身で鋭い目つきの男性。**鹿撃ち帽（ディアストーカー）とインヴァネスコート**。パイプ可 |
| `p-watson.jpg` | 口髭を蓄えた実直そうな中年男性。ヴィクトリア朝の服装 |
| `p-hudson.jpg` | 年配の女性。エプロン姿 |
| `p-mycroft.jpg` | 恰幅の良い年上の男性。上等な服装 |
| `p-lestrade.jpg` | 小柄で機敏そうな男性。地味な背広 |
| `p-moriarty.jpg` | 額の広い、痩せた年配の男性。暗い印象 |
| `p-adler.jpg` | ヴィクトリア朝の装いの女性。舞台衣装風 |
| `p-moran.jpg` | 日焼けした軍人風の年配男性 |
| `p-irregulars.jpg` | 数人の子供のシルエット。街角 |

**9枚の画風を完全に統一すること。** 同じプロンプトの骨格を使い回す。

```
統一する要素：
- 19世紀末の証明写真（studio portrait）風。セピア／褪色した銀塩写真の質感
- 胸から上、正面ないしやや斜め。同じ画角
- 背景は一様な暗い色。小物を置かない
- 照明は同じ向き（やや左上から）
- 粒子・わずかな傷。ただし顔が判別できる程度に留める
```

### ヒーロー用 1枚

| ファイル名 | 内容 |
|---|---|
| `hero-desk.jpg` | 探偵の机を真上から見た構図。**茶色のツイード生地の上に、鹿撃ち帽・虫眼鏡・パイプ・書類・インク壺**を並べる。人物なし。横長（16:9以上） |

**上に文字を重ねるので、全体的に暗めか、明暗の落ち着いた絵にすること。**

### 画像の厳守事項

- **画像内に文字を一切描かせない**（生成画像の文字は必ず崩れる。文字はHTMLで乗せる）
- **実在の俳優や既存の映像作品に似せない。** ホームズは映像化が非常に多いため、
  特定の俳優に似た画像は肖像権の問題を生む。匿名的な人物像にすること
- ファイルサイズ：ポートレートは **各120KB以下**、ヒーローは **300KB以下**。
  超える場合は縮小・再圧縮する（S3 に上げるものなので軽さが直接効く）
- ポートレートは正方形、ヒーローは横長
- **生成に失敗した画像があれば、代替を探さずに報告すること。**
  その人物は写真枠に頭文字（イニシャル）を表示して代替する。
  画像が無くてもレイアウトが崩れないこと

## 2. `index.html` の作り替え

### 保持すること（変えない）

- 内容のテキストは**現在の9人分をそのまま使う**。文言を変えない、足さない
- レイアウトの型：1カラム ＋ ヘッダーナビ ＋ ヒーロー ＋ カードグリッド
- `<link rel="stylesheet" href="dist/output.css">` のみ。**CDN の script は使わない**
- セマンティックタグ、`h1` は1つ、見出しレベルを飛ばさない
- 「本文へスキップ」リンク

### ヘッダー

- ツイードの濃色の帯。**下端に千鳥格子の細い帯**（高さ 6px 程度）を走らせる
- 左：鹿撃ち帽のSVGアイコン ＋ `CASE FILES` を等幅フォントで、文字間を広く
- 右：ページ内リンク（登場人物／正典について）
- `sticky top-0`

### ヒーロー

- 背景に `hero-desk.jpg`。上に暗いオーバーレイを重ね、
  **文字とのコントラスト比 4.5:1 以上**を確保する
- 中央にタイプライター体の書類ヘッダーを模したブロックを置く：
  ```
  METROPOLITAN POLICE — CASE FILES
  ─────────────────────────────
  ベイカー街の9人
  ─────────────────────────────
  SUBJECTS: 09    STATUS: OPEN
  ```
  （この英字は装飾。日本語の見出し `ベイカー街の9人` が `<h1>`）
- 赤いスタンプ `CONFIDENTIAL` を傾けて右上あたりに重ねる（`rotate-[-8deg]`）

### 人物カード（9枚）

1枚の書類に見せる。中身の並びは次のとおり。

```
┌────────────────────────────┐
│ CASE FILE No. 001    [写真] │  ← 番号は等幅、写真は右上に四角で
│                             │
│ シャーロック・ホームズ        │  ← h3、セリフ体
│ Sherlock Holmes             │  ← 等幅、小さく、褪せた色
│ - - - - - - - - - - - - - - │  ← 破線
│ 職業  諮問探偵               │  ← dl。原稿にある項目だけ
│ 住所  ロンドン ベイカー街221B │
│ 初登場 緋色の研究（1887年）   │
│ - - - - - - - - - - - - - - │
│ 解説文…                     │
└────────────────────────────┘
```

- カードは `bg-card`、細い実線の枠、わずかな影
- **カードをごく僅かに傾ける**（`rotate-[0.3deg]` と `rotate-[-0.4deg]` を交互に）。
  紙を重ねた雰囲気を出すため。**傾けすぎない**（読みにくくなる）
- ホバー時：傾きを 0 に戻し、少し持ち上げる（`hover:rotate-0 hover:-translate-y-1`）
  → 「1枚だけ引き抜いて見ている」感じになる
- 写真は正方形、角丸なし、セピア。細い枠を付ける
- **写真の下に等幅で撮影票風のラベル**を置く（例：`NO. 001`）

### スタンプの使いどころ（多用禁止）

赤いスタンプを置くのは**次の3枚だけ**。全部に置くと効果が消える。

| 人物 | スタンプ | 理由 |
|---|---|---|
| モリアーティ教授 | `WANTED` | 犯罪組織の首領 |
| セバスチャン・モラン大佐 | `WANTED` | モリアーティの組織で最も危険とされた人物 |
| アイリーン・アドラー | `THE WOMAN` | ホームズが唯一そう呼んだ相手 |

**原稿に書かれている事実の範囲で選んでいる。** これ以外の人物にスタンプを足さないこと。

### 正典について

- 書類の余白に貼られたメモ、という体裁にする
- 数字3枚（60 / 4 / 56）は、伝票の数字欄のように等幅で大きく

### フッター

- ヘッダーと同じ濃色。書類の綴じ込み欄に見立てる
- パブリックドメインの但し書きは必ず残す

## 3. レスポンシブ

- カードグリッド：`grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`
- 320px / 768px / 1440px の3幅で横スクロールが出ないこと
- **狭い画面ではカードの傾きを 0 にする**（狭いと傾きが目立ちすぎるため）

## 4. アクセシビリティ

- すべての `<img>` に `alt` を書く。**「〜の画像」と書かない**
- ポートレートは `loading="lazy"`。ヒーローには付けない（最初に見えるため）
- 紙の色と文字色のコントラスト比 4.5:1 以上
- 赤いスタンプは**装飾**なので `aria-hidden="true"`。ただし
  「WANTED」が情報として意味を持つなら、代わりに読み上げ用のテキストを別途用意する
- `prefers-reduced-motion` でホバーのアニメーションを無効化する
  （Tailwind なら `motion-reduce:` プレフィックス）

## 5. ビルド

作り替えたあと、必ず本番用のビルドを実行すること。

```bash
npm run build     # = npx @tailwindcss/cli -i src/input.css -o dist/output.css --minify
```

**新しく使ったクラスがビルドに含まれていないと、見た目が反映されない。**
ビルド後の `dist/output.css` のサイズを報告すること。

## 6. 内容の正確さ

現在の `index.html` に書かれている9人の情報を**変えない・足さない**。
年号・作品名・肩書きを創作しないこと。
人物ごとに項目数が違う（ハドスン夫人には初登場の記載がない等）。**無い項目を埋めないこと。**

## 7. 触らないファイル

- `package.json` / `package-lock.json` / `node_modules/`
- `SPEC_redesign.md`（このファイル）

- ポートレートで統一に使ったプロンプトの骨格
- `dist/output.css` のビルド後サイズ
- `index.html` の行数
- 画像を含めた S3 アップロード対象の合計サイズ
