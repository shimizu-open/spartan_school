# かけら UX 定義書

version 1.0 / 2026-07-31

本書は**画面の分け方と遷移**を定める。機能の定義は REQUIREMENTS.md、見た目と文言は DESIGN.md に従う。
本書と REQUIREMENTS.md の記述が食い違う場合、**画面構成と遷移については本書を優先する**（第7章に、書き換えが必要な箇所を列挙する）。

---

## 1. 何のための画面か

このアプリが集めるのは三つ（REQUIREMENTS 0.1）。だが、**三つは同じ頻度で起きない。**

| 行為 | 頻度 | 一回あたり |
|---|---|---|
| 今日の一行を置く | 1日1回 | 10秒 |
| 今月のひとつを決める／行った | 月1回 | 20秒 |
| 読み返す | 60日後に初めて。それまでは直近7日のみ | 数分 |

### 1.1 いまの構造の誤り

現在の実装は、この三つを**同じ階層のタブに並べている**。これは二つの意味で目的に反する。

1. **低頻度のものが常時見えていると、未達の表示として働く。**
   「今月のひとつ」が毎日タブに居座れば、決めていない月・行っていない月には、それが毎日目に入る。実行率を出さないと決めた FR-3.7・FR-3.8・NG-9 は、一覧を作らないことだけでは守れない。**常時そこにあること自体が、達成状況の可視化になる。**

2. **起動直後に選択肢が三つあると、書くまでに判断が要る。**
   「開いて十秒で書ける」（REQUIREMENTS 0.3）は、入力欄が最初に出ることだけでは達成されない。**他に何も出ていないこと**が必要である。

`lg` で三画面を同時に見せる設計（NFR-4）は、この誤りを最も強く出す。書く場所と、読み返す場所と、月の目的が、同時に同じ重さで見えている。

### 1.2 本書が採る構造

> **「今日」を根とした、行き止まりのある一本道。**

- 起動して目に入る画面は**一つだけ**
- 他の画面へは、**用がある日にだけ**、一行の入口が現れる
- 戻り先は常に「今日」。深さは最大2

## 2. 日々のループ

### 2.1 毎日（これが本体）

```
開く → 書く → 置く → 閉じる
```

この間に、他の要素を**一つも挟まない**。

| 段階 | 画面に在るもの | 所要 |
|---|---|---|
| 開く | 日付・入力欄（フォーカス済み）・「なし」・「＋ 済・人」・記録する | 0秒 |
| 書く | 同上 | 5秒 |
| 置く | 記録カード・今日の一言 | 1秒 |
| 閉じる | — | — |

「置く」まで到達した時点で、その日の用は終わっている。**それ以降は、何も要求しない。**

### 2.2 月に一度

「ひとつ」への入口は、画面の**最下部**に「これまでを見る」と対で常時置く。ラベルは「今月のひとつ」。
**扉があるだけで、中の状況は外から見せない。** 決めていない月も、行っていない月も、扉の見た目は変わらない。

| 今月の状態 | その日の記録がある画面に、追加で出るもの |
|---|---|
| 目的が未登録 | **何も出さない**（扉で足りる） |
| 目的が登録済み・未実行 | `◇ 中華そばを食べる` ＋［行った］（その場で1タップ） |
| 実行済み | **何も出さない**（済んだことを再表示しない） |

月が変われば枠は新しくなり、前月が未実行でも**表示・履歴のいずれにも残さない**（FR-3.7）。

> 常時の入口を置く以上、「今月のひとつを決めますか」という提案は出さない。扉があるのに毎日誘えば、それは催促である。
> 常駐が未達の可視化にならないのは、**扉のラベルが状態によって変わらない**からである。件数も色の差も付けない。

### 2.3 二か月に一度

開放（FR-2.4）は、**置いたあとの画面に一度だけ**「読み返せます」として現れる。押すと「かけら」へ。
それ以外の日、読み返しへの入口は**画面の最下部**にだけある。探せば必ずあるが、書く邪魔をしない位置に置く。

## 3. 画面一覧

| # | 画面 | 役割 | 到達方法 |
|---|---|---|---|
| 1 | **今日** | その日の一行を置く | 起動時。すべての戻り先 |
| 2 | **ひとつ** | 今月の目的を決める／書き換える | 今日の最下部・右の入口から |
| 3 | **かけら** | 記録を見る | 今日の最下部・左の入口／開放の報せから |
| 4 | **このアプリについて** | 保存先の説明・控え・やめる | かけらの最下部から |
| 5 | **はじめて** | 初回の説明 | 初回起動時に一度／かけら・このアプリについてから再表示 |

**タブは置かない。** 画面下部の固定ナビゲーションを廃止する。

## 4. 遷移

```
  ┌──────────┐  初回のみ
  │ はじめて  │
  └────┬─────┘
       │「はじめる」
       ▼
  ╔═══════════════════════════════════╗
  ║              今日                  ║ ◀── 起動時は必ずここ
  ║  （書く前）                        ║
  ║   日付／入力欄／なし／＋ 済・人      ║
  ║   ［記録する］                     ║
  ╟───────────────────────────────────╢
  ║  （置いたあと）                    ║
  ║   記録カード ＋ 今日の一言          ║
  ║   ─ 用がある日だけ、一行 ─          ║
  ║   「今月のひとつを決めますか」 ─────╫──▶ ひとつ
  ║   ◇ 目的 ［行った］                ║      （その場で完了／戻らない）
  ║   「読み返せます」（開放日のみ）─────╫──▶ かけら
  ║                                   ║
  ║   これまでを見る ──────────────────╫──▶ かけら
  ╚═══════════════════════════════════╝
                                          │
                                          ▼
                                   ┌──────────────┐
                                   │   かけら      │
                                   │ ← 今日        │
                                   └──────┬───────┘
                                          ▼
                                 ┌────────────────────┐
                                 │ このアプリについて   │
                                 │ ← かけら            │
                                 └────────────────────┘
```

| 規則 | 内容 |
|---|---|
| 深さ | 最大2（今日 → かけら → このアプリについて） |
| 戻る | 各画面の左上に「← 今日」「← かけら」。ブラウザの戻るでも同じ動きにする |
| 起動 | 常に「今日」。前回どの画面を見ていたかを覚えない |
| 日付をまたいだ場合 | 再表示時に「今日」の書く前の状態へ戻す（FR-1.10） |
| 「行った」 | その場で印が変わるだけ。画面遷移しない |

### 4.1 広い画面（`lg` 以上）

**三画面を同時に表示しない。1カラムのまま、余白だけを増やす。**

| 幅 | 扱い |
|---|---|
| 〜639 | 本文カラム全幅（左右余白 20） |
| 640〜1023 | 本文カラム最大 560、中央寄せ |
| 1024〜 | 本文カラム最大 620、中央寄せ。**カラムを増やさない** |

広い画面で得るのは、同時に見える情報量ではなく、**一行のまわりの静けさ**である。

## 5. 各画面に出さないもの

「出すもの」より、**出さないもの**を先に決める。

### 5.1 今日（書く前）

| 出さない | 理由 |
|---|---|
| 画面名（「今日」の語） | 日付があれば分かる。器が二度名乗らない |
| 他の画面への入口（最下部の一行を除く） | 書く前に、書く以外の選択肢を出さない |
| 今月のひとつ | 書く前に、別の未着手を見せない |
| 昨日までの記録 | 書く前に読み返させない |
| 今日の一言 | 置いたことの結果であり、開いた報酬ではない |
| 文字数、残り字数 | 数値は日付だけ（NG-1） |

### 5.2 今日（置いたあと）

| 出さない | 理由 |
|---|---|
| 称賛・効果音・祝祭 | FR-1.9 |
| 連続日数・記入率 | NG-1 |
| 実行済みの月の外出 | 済んだことを再掲しない |
| 次にすべきことの提示 | その日の用は終わっている |

### 5.3 ひとつ

| 出さない | 理由 |
|---|---|
| 過去の月の一覧（開放前） | FR-3.9 |
| 未実行だった月 | FR-3.8・NG-9 |
| 予定日までの残り日数 | NG-10 の趣旨 |
| 「まだ行っていません」の類 | 不足を指摘しない（DESIGN 7章） |

### 5.4 かけら

| 出さない | 理由 |
|---|---|
| 開放までの残り日数 | NG-10 |
| 未記入日の警告色・「未記入」の語 | FR-2.3 |
| 記入した日数・割合 | NG-1 |
| 一年前の今日 | NG-4 |

### 5.5 このアプリについて

| 出さない | 理由 |
|---|---|
| 記録の内容 | FR-5.2 |
| 「やめる」の目立つ配置 | 距離で止める（DESIGN 5.4） |

## 6. 状態ごとの見え方

同じ「今日」の画面が、状態によって何を出すか。

| # | 状態 | 出るもの |
|---|---|---|
| 1 | 初回起動 | 初回説明 →「はじめる」→ このアプリについて（使い方）→「はじめる」→「今日（書く前）」。入力欄にフォーカス |
| 2 | 2日目以降・未記入 | 今日（書く前）。入力欄にフォーカス |
| 3 | 記録済みの日に開き直す | 記録カード（押すと書き直せる）＋ 今月の状態に応じた一行（5〜7 と同じ）。**今日の一言は出さない**（FR-8.5） |
| 4 | 今書いて置いた直後 | 記録カード ＋ 今日の一言 |
| 5 | 4 かつ 今月の目的が未登録 | ＋「今月のひとつを決めますか」 |
| 6 | 4 かつ 目的あり・未実行 | ＋ `◇ 目的` ［行った］ |
| 7 | 4 かつ 実行済み | 追加なし |
| 8 | 4 かつ 開放当日 | ＋「読み返せます」 |
| 9 | 記録が0件でかけらを開いた | 「今日のぶんから始まります」 |

**3 と 4 の違いは「今日の一言」だけである。** 一言はその日一度きり、置いた瞬間にだけ現れる。開き直しても出ない。
一方、**「ひとつ」の一行は、今日の記録がある間ずっと出す。** 朝に記録を置き、夕方に外出して帰ってきた人が「行った」を押せなくなるためである。
書く前の画面に出さないことが要点であって、置いたあと一度きりにする理由はない。

## 8. 決定の根拠（要約）

| 決定 | 根拠 |
|---|---|
| タブを廃止する | 低頻度の機能の常駐は、未達の可視化として働く（FR-3.7・NG-9 の趣旨） |
| 起動画面を一つにする | 「開いて十秒で書ける」は、他に何も無いことで初めて成立する |
| 「ひとつ」を条件付きで出す | 用がある日にだけ現れれば、催促にならず、機会は逃さない |
| 実行済みの月は何も出さない | 済んだことの再掲は、達成の表示に近づく |
| 読み返しを最下部に置く | 開放前は7日しか見えない。毎日通る場所に置く価値がない |
| `lg` で1カラムを保つ | 広い画面で増やすべきは情報量ではなく余白 |
